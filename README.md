# Python Number Guessing Game

A beginner-friendly Python command-line game where the player guesses a randomly generated number. Features multiple difficulty levels, input validation, guess tracking, and a halfway “give-up” option.



---

## Features

- Three difficulty levels:
  - Easy (1–10)
  - Medium (1–50)
  - Hard (1–100)
- Maximum attempts per level
- Halfway “give-up?” prompt to test persistence
- Tracks number of guesses
- Displays all guesses at the end
- Input validation to prevent invalid entries

---

## Skills Practiced

- Python basics
- Loops (`while`)
- Conditionals (`if/elif/else`)
- Functions
- Random number generation (`random` module)
- User input handling
- Program flow and basic game logic
